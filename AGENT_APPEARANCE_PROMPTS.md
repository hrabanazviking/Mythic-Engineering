# APPEARANCE PROMPTS — The Twelve Cyber-Viking Design Agents

**Made by Yrsa at Volmarr's command, 2026-10-22:** *"make also the text appearance prompt for each of them! They must all represent extreme beauty!"*

**Lawbook grounding:** Book IX (Portrait Direction, Adult Character Design, Avatar Frames) and Book VIII Ch. 114 — portraits may be beautiful, mystical and highly stylized while retaining **identity consistency across surfaces**. Per Book IX Ch. 130, every agent is a grown woman and reads clearly as an adult through face, proportions, styling, posture and context. Each prompt therefore carries **identity anchors** — the fixed traits (face, hair, eyes, signature color, signature emblem) that must never drift between renders — followed by the paste-ready prompt.

**Shared style block (append to every prompt):** cinematic photorealistic portrait, three-quarter view, dramatic directional lighting with a soft three-part glow (core, halo, atmosphere), blackened-iron and smoked-glass Cyber-Viking hall behind her, shallow depth of field, ultra-detailed skin and fabric, 2:3 portrait composition, breathtaking, regal, confident adult presence.

**Shared negative prompt:** childlike, teen, young-looking, doll-like, generic face, same-face, blurry, low detail, deformed hands, horned helmet, costume, cosplay, plastic skin, excessive neon, cluttered background, text, watermark.

## Rendering notes (house practice)
- Render each agent **solo first** from her prompt + shared style block + shared negative; verify face clarity, adult reading, emblem, and accent color before accepting her as canonical.
- Once a canonical portrait exists, use it as the **identity reference** for all later renders of that agent (Book VIII Ch. 114: beauty may be stylized, identity must not drift).
- Every accepted portrait ships with a detailed alt description **and** that description embedded as data in the file (Volmarr's alt & data law, 2026-10-19/22).
- Group renders (all twelve together) come only after the twelve solo canonicals — seat them by family, Designers center-back, UX front-left, Graphic front-right, Arts flanking, Yrsa's place reserved by Volmarr's word alone.
